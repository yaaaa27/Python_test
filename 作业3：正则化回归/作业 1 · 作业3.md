# 作业 1 · 推导题

**题目：** 证明正交设计下 $\widehat{\boldsymbol\beta}_{\text{Ridge}} = \dfrac{1}{1+\lambda}\widehat{\boldsymbol\beta}_{\text{OLS}}$。

### 证明

岭回归的闭合解为：

$$
\widehat{\boldsymbol\beta}_{\text{Ridge}}=\big(X^{T}X+\lambda I\big)^{-1}X^{T}Y
$$

正交设计意味着 $X^{T}X=I$。将其代入：

$$
\widehat{\boldsymbol\beta}_{\text{Ridge}}
=\big(I+\lambda I\big)^{-1}X^{T}Y
=\big((1+\lambda)I\big)^{-1}X^{T}Y
$$

由于标量 $(1+\lambda)$ 与单位矩阵可交换，且 $I^{-1}=I$：

$$
\big((1+\lambda)I\big)^{-1}=\frac{1}{1+\lambda}I
$$

于是：

$$
\widehat{\boldsymbol\beta}_{\text{Ridge}}
=\frac{1}{1+\lambda}I\cdot X^{T}Y
=\frac{1}{1+\lambda}X^{T}Y
$$

又因为 $X^{T}X=I$，所以 $(X^{T}X)^{-1}=I^{-1}=I$，因此：

$$
\widehat{\boldsymbol\beta}_{\text{OLS}}
=(X^{T}X)^{-1}X^{T}Y
=I\cdot X^{T}Y
=X^{T}y
$$

代入上式得：

$$
\boxed{\ \widehat{\boldsymbol\beta}_{\text{Ridge}}
=\frac{1}{1+\lambda}\widehat{\boldsymbol\beta}_{\text{OLS}}\ }
$$

**结论：** 在正交设计下，岭回归估计量等于 OLS 估计量乘以一个统一的缩放因子 $\dfrac{1}{1+\lambda}$。由于 $\lambda>0$，该因子严格小于 1，因此所有系数被等比例向 0 收缩，但永远不会精确等于 0。

# 作业 3 · 分析题

**题目：** 为什么正则化前必须 Z-score 标准化？不做的后果是什么？

### 一、惩罚项对系数“一视同仁”

### 二、量纲不同导致惩罚“不公平”

若特征未标准化，不同变量的量纲差异巨大

- **量纲大的变量**：其系数 $\beta_j$ 天然很小（因为 $x_j$ 很大，只需很小的系数就能产生相同影响）。于是 $\beta_j^2$ 或 $|\beta_j|$ 很小，不受惩罚。
- **量纲小的变量**：其系数 $\beta_j$ 天然很大，于是被惩罚项**过度压缩**，即使该变量真实重要。

结果：**惩罚强度被量纲“绑架”**，正则化失去公平性

### 三、未中心化时截距项被误罚

若未对 $y$ 和 $X$ 做中心化处理，模型通常写成：

$$
y_i=\beta_0+\sum_{j=1}^{p}x_{ij}\beta_j+\varepsilon_i
$$

此时惩罚项 $\lambda\sum_{j=1}^{p}\beta_j^2$ 若把 $\beta_0$ 也纳入（或未中心化导致 $\beta_0$ 与特征均值耦合），会**对截距项也施加惩罚**，迫使截距向 0 收缩，破坏模型的无偏性基础。

### 四、不标准化的后果总结

| 后果         | 说明                                           |
| ------------ | ---------------------------------------------- |
| 惩罚不公平   | 量纲大的变量几乎不受罚，量纲小的变量被过度压缩 |
| 系数不可比   | 无法通过系数大小判断变量重要性                 |
| 模型选择偏差 | Lasso 可能错误地保留/删除变量                  |
| 截距被误罚   | 未中心化时截距向 0 收缩，预测产生系统偏差      |

**结论：** 正则化前必须进行 Z-score 标准化，否则惩罚强度被量纲“绑架”，正则化失去公平性，模型结果既不可解释也不可靠。
